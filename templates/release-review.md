# Safety / release review

Project, build, HSI and safety baseline; complete SWE.1–SWE.6 evidence ledger; applicable ISO 26262 Part 6/8 method suitability; tool confidence/qualification; HIL status; trace and non-functional budgets; approved deviations; open/inconclusive anomalies; independent review results; separation-of-duties and authenticated approval.

Outcome: APPROVE / REJECT / CONDITIONAL (with explicit action and accountable owner). Conditional must not be interpreted as unrestricted production release.
