# Tool confidence / qualification assessment (ISO 26262-8)

Tool name/version/hash/license; purpose/use case and work product consumed; possible erroneous output and consequences; Tool Impact TI and Tool Error Detection TD with evidence; derived TCL; confirmation/qualification strategy if needed; compiler/runtime constraints; test of tool behavior and known limitations; update/reassessment triggers; authorized review signature.

Assess generative AI, CI parsers and custom internal tools for *their actual use cases*. Do not assume vendor marketing, 'MCP available' or 'MISRA checker installed' constitutes ISO 26262 tool qualification.
