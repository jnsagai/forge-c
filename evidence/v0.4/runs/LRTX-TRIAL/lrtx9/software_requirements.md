# Software requirements

Software requirements of the IWDG LL driver for this work order. Scope: LL (header-only, static inline): read/write IWDG registers through the generated register-block array ll_iwdg_regs (extern; placed at the IWDG base by the linker, defined in RAM by host tests), indexed by the generated LL_IWDG_<REG>_OFFSET / 4U Start the watchdog and refresh the counter by writing the documented keys to IWDG_KR; enable and disable write access to IWDG_PR, IWDG_RLR and IWDG_WINR with the documented keys Set the prescaler (IWDG_PR.PR) and the reload value (IWDG_RLR.RL); query the update flags in IWDG_SR (PVU, RVU) and the watchdog enable status (ONF) (no waiting: the caller bounds its polling) Out of scope: HAL API, window option (IWDG_WINR), early wake-up interrupt (IWDG_EWCR, IWDG_ICR), hardware watchdog option bytes, low-power freeze, debug freeze

- **SWR-001** The IWDG LL driver shall write the key value 0x0000AAAA to the IWDG_KR.KEY field when refreshing the watchdog counter.
  - Source: RM0486 p.2989
  - Verification: Host unit test passes when the register array at ll_iwdg_regs[IWDG_KR_OFFSET/4U] contains the value 0x0000AAAA after a call to the refresh function.
- **SWR-002** The IWDG LL driver shall write the key value 0x00005555 to the IWDG_KR.KEY field when enabling write-accesses to IWDG_PR and IWDG_RLR registers.
  - Source: RM0486 p.2989
  - Verification: Host unit test passes when the register array at ll_iwdg_regs[IWDG_KR_OFFSET/4U] contains the value 0x00005555 after a call to the enable write-access function.
- **SWR-003** The IWDG LL driver shall write the key value 0x0000CCCC to the IWDG_KR.KEY field when starting the watchdog.
  - Source: RM0486 p.2989
  - Verification: Host unit test passes when the register array at ll_iwdg_regs[IWDG_KR_OFFSET/4U] contains the value 0x0000CCCC after a call to the start watchdog function.
- **SWR-004** The IWDG LL driver shall write a value different from 0x5555 to the IWDG_KR.KEY field when disabling write-accesses to IWDG_PR and IWDG_RLR registers.
  - Source: RM0486 p.2989
  - Verification: Host unit test passes when the register array at ll_iwdg_regs[IWDG_KR_OFFSET/4U] contains a value other than 0x00005555 after a call to disable write-access function.
- **SWR-005** The IWDG LL driver shall read the value of IWDG_PR.PR to determine the current prescaler.
  - Source: RM0486 p.2990
  - Verification: The test passes when reading from ll_iwdg_regs[IWDG_PR_OFFSET/4U] returns the expected predivider value.
- **SWR-006** The IWDG LL driver shall not write to IWDG_RLR.RL before enabling write access to the register via IWDG_KR.KEY.
  - Source: RM0486 p.2990
  - Verification: A target robot test passes when no write to IWDG_RLR.RL occurs after reset while no LL function has been called.
- **SWR-007** The IWDG LL driver shall read the value of IWDG_RLR.RL for status query purposes.
  - Source: RM0486 p.2990
  - Verification: A host unit test passes when reading IWDG_RLR.RL returns the expected reload value from ll_iwdg_regs[IWDG_RLR_OFFSET/4U].
- **SWR-008** The IWDG LL driver shall return 1U when the IWDG_SR.EWIF field is set, else 0U.
  - Source: RM0486 p.2991
  - Verification: The host unit test passes when ll_iwdg_regs[IWDG_SR_OFFSET / 4U].b.EWIF is read and the returned value matches the expected bit state.
- **SWR-009** The IWDG LL driver shall return 1U when the IWDG_SR.ONF field is set, else 0U.
  - Source: RM0486 p.2991
  - Verification: The host unit test passes when ll_iwdg_regs[IWDG_SR_OFFSET / 4U].b.ONF is read and the returned value matches the expected bit state.
- **SWR-010** The IWDG LL driver shall return 1U when the IWDG_SR.EWU field is set, else 0U.
  - Source: RM0486 p.2991
  - Verification: The host unit test passes when ll_iwdg_regs[IWDG_SR_OFFSET / 4U].b.EWU is read and the returned value matches the expected bit state.
- **SWR-011** The IWDG LL driver shall query the IWDG_SR.WVU field and return 1U when it is set, else 0U.
  - Source: RM0486 p.2994
  - Verification: The host unit test passes when the function returns 1U if IWDG_SR.WVU bit is set in the ll_iwdg_regs array, otherwise 0U.
- **SWR-012** The IWDG LL driver shall query the IWDG_SR.RVU field and return 1U when it is set, else 0U.
  - Source: RM0486 p.2994
  - Verification: The host unit test passes when the function returns 1U if IWDG_SR.RVU bit is set in the ll_iwdg_regs array, otherwise 0U.
- **SWR-013** The IWDG LL driver shall query the IWDG_SR.PVU field and return 1U when it is set, else 0U.
  - Source: RM0486 p.2994
  - Verification: The host unit test passes when the function returns 1U if IWDG_SR.PVU bit is set in the ll_iwdg_regs array, otherwise 0U.
- **SWR-014** When the IWDG LL driver is requested to start the watchdog, the IWDG LL driver shall write the value 0xCCCC to IWDG_KR.KEY.
  - Source: RM0486 p.2980
  - Verification: host_unit_test passes when IWDG_KR.KEY is written with 0xCCCC
- **SWR-015** When the IWDG LL driver is requested to refresh the watchdog counter, the IWDG LL driver shall write the value 0xAAAA to IWDG_KR.KEY.
  - Source: RM0486 p.2980
  - Verification: host_unit_test passes when IWDG_KR.KEY is written with 0xAAAA
- **SWR-016** When the IWDG LL driver is requested to enable write access to IWDG_PR and IWDG_RLR, the IWDG LL driver shall write the value 0x5555 to IWDG_KR.KEY.
  - Source: RM0486 p.2980
  - Verification: host_unit_test passes when IWDG_KR.KEY is written with 0x5555
- **SWR-017** When the IWDG LL driver is requested to disable write access to IWDG_PR and IWDG_RLR, the IWDG LL driver shall write a value different from 0x5555 to IWDG_KR.KEY.
  - Source: RM0486 p.2980
  - Verification: host_unit_test passes when IWDG_KR.KEY is written with any value other than 0x5555
- **SWR-018** The IWDG LL driver shall write a valid prescaler divider value to IWDG_PR.PR.
  - Source: RM0486 p.2980
  - Verification: host_unit_test passes when IWDG_PR.PR is written with a 4-bit value in range [0..15]
- **SWR-019** The IWDG LL driver shall write the requested reload value to IWDG_RLR.RL when a function sets the watchdog reload value.
  - Source: RM0486 p.2980
  - Verification: host_unit_test passes when IWDG_RLR.RL is written with a 12-bit value in range [0..4095]
- **SWR-020** While no LL function has been called after reset, the IWDG LL driver shall not write any IWDG register.
  - Source: RM0486 p.2980
  - Verification: target_robot_test passes when no IWDG register is written before calling any LL function
- **SWR-021** The IWDG LL driver shall occupy at most 4096 bytes of flash.
  - Source: work-order budget (owner development target)
  - Verification: SWE.6 Robot suite checks the target linker map, size-tool and stack-usage evidence of the driver image; passes when the driver flash usage is at most 4096 bytes.
- **SWR-022** The IWDG LL driver shall use at most 64 bytes of static RAM.
  - Source: work-order budget (owner development target)
  - Verification: SWE.6 Robot suite checks the target linker map, size-tool and stack-usage evidence of the driver image; passes when the driver-owned data and BSS total at most 64 bytes, excluding the externally provided register array.
- **SWR-023** The IWDG LL driver shall use at most 128 bytes of stack for any public API call.
  - Source: work-order budget (owner development target)
  - Verification: SWE.6 Robot suite checks the target linker map, size-tool and stack-usage evidence of the driver image; passes when the worst-case stack usage of every public API call chain is at most 128 bytes.
